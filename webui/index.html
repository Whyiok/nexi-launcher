Advanced: Azure Client ID

A built-in Client ID is already configured — leave the field empty to use it. Paste your own Azure application ID only if you want a different app registration.

How to get your own Client ID (free, ~5 minutes)
  1. Open portal.azure.com and sign in.
  2. Go to Microsoft Entra ID → App registrations → New registration.
  3. Name it anything, pick Personal Microsoft accounts only, then press Register.
  4. Copy the Application (client) ID from the overview page.
  5. Open Authentication, set Allow public client flows to Yes and save.
  6. Paste the ID above, press Save, then Sign in.

Advanced: browser sign-in (OAuth) setup

Browser sign-in only needs an Ely.by Client ID for a “Desktop application” (PKCE, no secret). A “Website” app also works — then paste its Client Secret too. Enter them here once; everyone using this copy of the launcher can then sign in with the button above.

How to get a Client ID (and a Secret)
  1. Open account.ely.by and sign in.
  2. Open your applications page and create a new application. Desktop application is the simplest choice: it uses PKCE, so only a Client ID is needed. Website also works but then the Client Secret is required.
  3. Add the exact Redirect URI shown above (by default http://localhost:26206/ely-callback) to that application.
  4. Copy the application's Client ID — and its Client Secret if it has one — into the fields above and press Save.
  5. Press Sign in with browser.

Offline accounts skip signing in. The game uses the name you type here; skins come from the profile files.
